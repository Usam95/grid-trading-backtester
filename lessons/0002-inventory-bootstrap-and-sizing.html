Lesson 0002 · Capital · 12–15 minutes

Every sell must be backed by BTC the grid actually owns.

By the end, you can calculate bootstrap inventory, distinguish account holdings from grid inventory, and explain why MVP profit does not resize later orders.

Module home → Inventory, bootstrap, and sizing

Mental model

Neutral means two-sided readiness—not zero risk.

A spot grid owns BTC and therefore loses value when BTC falls. It is not market-neutral.

Account base holdings

All BTC visible in the Binance account, including BTC unrelated to this grid.

Grid inventory

BTC explicitly allocated to this run and tracked by its ledger.

Backing inventory

The part reserved to fulfill every currently planned sell obligation.

why a real acquisition is required

A BTC/USDT grid activates near 100,000 USDT with initial sell rungs at 105,000, 110,000, and 115,000. Each sell represents 100 USDT of quote value. The grid needs approximately:

100/105,000 + 100/110,000 + 100/115,000 = 0.002731 BTC

Live activation submits an aggressive, journaled acquisition for the required net BTC plus approved fee and rounding shortfall. That order incurs real price, fee, and slippage. A database entry that merely changes USDT into BTC would be synthetic and cannot back live orders.

Obligation first

Bootstrap size comes from sells, not a percentage.

“Use half the capital” is convenient but unrelated to the actual sell quantities.

Calculation sequence

  1. Generate and venue-round every initial sell quantity.
  2. Sum those base obligations.
  3. Add the configured fee reserve or acquire a base-fee shortfall.
  4. Confirm net credited base before placing any rung.
required backing = Σ rounded sell quantities + approved shortfall reserve

Incomplete acquisition

If 1.000 BTC is required but only 0.800 BTC is confirmed, the run stays bootstrapping. It does not silently shrink sells or place a partially backed ladder.

Retries are allowed only within approved price, slippage, and time limits. Any acquired 0.800 BTC remains grid-owned and journaled while the operator reviews the failure.

Stable commitments

Fixed quote does not mean fixed BTC.

Equal quote commitments make exposure comparable; BTC quantity changes with rung price.
