Quick reference

Canonical grid semantics

A compact operating reference for the first spot-grid MVP. For explanations and exercises, use the complete learning module. The full canonical vocabulary remains in the project glossary.

Activation

Price must be strictly inside immutable bounds. Bootstrap acquires real backing inventory. No ladder appears until inventory is confirmed.

Normal cycle

Post-only buy fills pair one rung higher. Paired sells use actual net base received. Replacement buys keep fixed quote value.

Post-only rejection

Reconcile and refresh, then retry maker-safe within strict bounds and never worse than rung economics. Never fall back to taker; pause and alert when limits are exhausted.

Outer bounds

Lowest rung is buy-only; highest is sell-only. They cycle only inward; no rung, order, or exposure is created outside the approved ladder.

Range-exhausted

Outside the range, create no new outer exposure. Retain inventory and valid inward recovery-side orders.

Pause

Cancel and block buys; keep valid inventory-reducing sells. Resume only after reconciliation and explicit approval.

Stop

Cancel all managed orders, reconcile late fills, then explicitly retain or liquidate. Retain is the safe default.

Emergency

Block commands, cancel all orders, reconcile, and retain inventory. Do not automatically liquidate during uncertain state.

Configuration

One immutable configuration version per run. Strategy changes create a new version and new evidence.

Viability

Every adjacent cycle must remain positive after fees, conservative execution allowance, rounding, and safety margin.
