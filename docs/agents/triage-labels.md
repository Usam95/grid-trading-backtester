# Triage Labels

| Canonical role | Local label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | More facts or a user decision are required |
| `ready-for-agent` | `ready-for-agent` | Fully specified for autonomous agent work |
| `ready-for-human` | `ready-for-human` | Human judgment, approval, credentials, or action is required |
| `wontfix` | `wontfix` | Deliberately declined or out of scope |
