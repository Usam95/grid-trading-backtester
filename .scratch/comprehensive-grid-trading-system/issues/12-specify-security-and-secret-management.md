## Answer

Use the accepted [security and secret-management specification](../../../analysis/security-and-secret-management-spec.md), grounded in the [security code-gap audit](../../../analysis/security-code-gap-audit.md). The personal MVP uses a source-IP-restricted dedicated SSH key as its sole human application-access gate; Studio performs only typed allowlisted system operation while exceptional VM administration remains SSH-terminal-only. Same-origin/browser-command protections, exact confirmations, Gateway/runtime admission, process/file/network isolation, and complete audit preserve safety without a second Gridlab login.

Production-Data Paper has no Binance credential. Testnet uses one atomic versioned bundle entered directly into Key Vault and read once at frozen startup through managed identity; no production key exists before separate live preparation. Testnet/live permissions are mutually exclusive, withdrawals/margin/futures/transfers are prohibited, secret values never enter any ordinary storage/evidence path, there is no scheduled MVP rotation, and suspected exposure requires frozen emergency replacement and reconciliation.

Detailed diagnostics use approved event fields plus a central redaction safety net and all-sink canary tests. Local qualified releases pin and hash every dependency, reproduce a clean offline bundle, and block applicable Critical/High or any authority/credential/evidence-impacting vulnerability. Azure platform encryption, TLS/SSH, laptop full-disk encryption, least-privilege RBAC/processes/files, executable compromise runbooks, and a comprehensive positive/negative acceptance matrix complete the baseline.

The permitted work laptop is non-live despite employer approval; real money requires an accepted operator-owned encrypted workstation and a replacement SSH key. The operator accepted no private-key backup, no Gridlab-managed Azure MFA/recovery, no routine Testnet rotation, the single-VM/root trust boundary, platform-managed encryption keys, sole-provider-account recovery dependence, and `SECURITY_MAINTENANCE_DEFERRED`. These remain visible residual risks and are mandatory release/acceptance evidence, not hidden waivers.
