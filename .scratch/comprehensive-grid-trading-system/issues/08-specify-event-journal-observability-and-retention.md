## Answer

Use the operator-approved [`analysis/event-journal-observability-spec.md`](../../../analysis/event-journal-observability-spec.md) as the MVP contract. It defines a decision-complete append-only journal with atomic processing/outbox transactions, typed causal/time/order evidence, immutable schema conversion, deterministic snapshots/replay and portable bundles; structured redacted JSONL logs, curated metrics, layered health, selective spans, durable incidents and external alerts; targeted production market capture, exact Parquet/Zstandard compaction, tiered retention and preservation holds; B1ms-first 64-GiB-local/Hot-ZRS-Blob operation with a measured resize gate; 15-minute RPO/60-minute RTO, ten-minute changed-state online recovery points, weekly restores/monthly full drills, retention-aware deletion; graded evidence-protection failure behavior; and the mandatory deterministic fault matrix. The current Azure price basis is recorded in [`analysis/azure-mvp-monthly-cost-estimate.md`](../../../analysis/azure-mvp-monthly-cost-estimate.md).

Implementation and paper/live promotion require the specified machine-readable evidence. Resolving this planning ticket does not assert that the current code implements the contract or authorize trading.
