## Answer

Use the accepted [minimal Azure deployment specification](../../../analysis/azure-minimal-deployment-spec.md), supported by the [primary-source Azure research](../../../analysis/azure-minimal-deployment-primary-research.md). The minimum topology is one non-zone-pinned Germany West Central B1ms-first Linux VM with a 64-GiB E6 LRS Standard SSD, Standard static public IPv4, GPv2 Hot ZRS Blob with eligible Cool tiering, managed identity plus one Standard Key Vault, and bounded Azure Monitor/Log Analytics. Native `systemd` supervises isolated Gateway, Production-Data Paper and Testnet processes; Bicep and locally qualified immutable bundles uploaded through source-IP-restricted SSH define deployment and releases. Application SQLite recoverable points target a 15-minute RPO and 60-minute frozen RTO without Azure VM Backup or application-level HA.

B1ms is accepted only after the exact 24-hour representative profile preserves the 384-MiB host-memory reserve, CPU credits, queues, persistence, evidence, recovery and safety deadlines; otherwise resize to B2als_v2 and then B2as_v2 with full requalification. Cost is estimated at EUR 24-30/month before VAT, with warning at EUR 35 and mandatory operator review at EUR 50. One resumable laptop-driven acceptance run proves deployment, isolation, permissions, Testnet commands, reconciliation, restart/recovery, monitoring/dead-man and capacity before an explicit shakedown and later 30-day qualifying clock.

The operator deliberately accepts `SECURITY_MAINTENANCE_DEFERRED`: no scheduled update discovery, download, installation, service restart, reboot, Livepatch or general drift scanner is present in the personal MVP. This is an explicit residual security risk and can yield only `ACCEPTED_WITH_SECURITY_EXCEPTION`, never a claim that the host is maintained or fully patched. Detailed authentication, Binance credential permission/cadence, cryptographic policy and hardening acceptance remain owned by [Specify security and secret management](12-specify-security-and-secret-management.md).
